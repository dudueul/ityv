# P0 출시 차단 게이트 / P0 Release Gates

> English summary: The 16 release-blocking gates inherited from K-Ballot, re-stated under the ityv design as ITYV-P0-01..16, plus nine new gates ITYV-P0-17..25 introduced by the E2E layer (receipt-freeness formal proof, subliminal-channel resistance, pad custody chain, chamber access structure and DKG transcript, imprinter qualification, interpretation-unit isolation, statutory constitution of the Independent Verification Committee, mandated-verifier readiness, destruction-ceremony rehearsal). Every gate is NOT_PROVEN. The release decision is NO_GO while any gate is open; no test pass, pilot result or document closes a gate without the independent evidence named in it.

상태: 전 게이트 `NOT_PROVEN`. 출시 판정: **`NO_GO`**. 게이트가 하나라도 열려 있으면 어떤 산출물도 실선거 사용 가능으로 표기하지 않는다(CONSTITUTION §5.5). 게이트의 정의를 바꾸거나 삭제하려면 ADR과 법무·감사·독립검증위원회 3자 결재가 필요하다(ITYV-REQ-DEL-004).

## 1. 게이트 구조

각 게이트는 주장(Claim), 필요한 독립 증거(Evidence), 반례(Defeater), 현재 상태, 담당 층으로 기술한다. 증거는 시험기관 서명과 재현 가능한 원시 데이터를 포함해야 하며, 반례가 하나라도 성립하면 게이트는 닫히지 않는다.

## 4. 게이트와 단계의 관계

- 0단계 시범(비구속)은 게이트를 닫을 필요가 없으며 V2까지의 소프트웨어 증거만 요구한다(ADR-0007).
- 2단계 이후의 어떤 구속력 있는 사용도 ITYV-P0-01..25 전부의 `PROVEN` 상태를 요구한다.
- 게이트 상태 변경은 `release_gate_evidence` 이벤트로 장부에 남기며 검증 기관, 증거 해시, 시점을 포함한다.
